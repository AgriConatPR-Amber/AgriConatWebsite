# AgriConat – ZZ Plant Showcase

Hobby website project presenting premium ZZ Plants (Zamioculcas zamiifolia) from AgriConat.

## Purpose
Informative site showcasing advantages, varieties, care guide, and featured ZZ plants in a clean, professional layout.

## Features
- Responsive navigation & smooth scrolling
- Section-based content with fade-in animations
- Product showcase grid (informational only – no sales)
- Simple contact form with client-side rate limiting
- Basic visitor tracking (localStorage)

## Setup
1. Place all files in the same directory.
2. Open `index.html` in a browser.
